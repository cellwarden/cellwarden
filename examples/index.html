CellWarden

A complete single-cell analysis, from QC to annotation, differential expression and Open Targets evidence. Its decisions are guarded: rules decide, LLM agents advise, a reviewer agent checks, and you approve.

ingest → QC → [QC review] → clustering → markers → [context review] → [annotation review] → DE + Open Targets → [interpretation review] → report

Example: 10x PBMC 3k

ReportQC, clusters, markers, cell types, differential expression, drugs and diseases from Open Targets, gate decisions, LLM cost.Open report → UMAP explorerColour the 2,700 cells by cell type, cluster or any gene.Open explorer → Run dashboardEvery stage with its time and memory, and the gates with their decisions.Open dashboard → A review gateThe annotation review: the evidence, the agent's proposal, the reviewer's verdict.Open gate report →

Produced by cellwarden run with every gate on auto, using NVIDIA NIM agents. Data: 10x Genomics PBMC 3k, CC BY 4.0. How it was made.
